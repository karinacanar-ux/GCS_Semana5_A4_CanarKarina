# API Inventario (mini)

- Endpoints simulados: GET /products, POST /products
- Objetivo: repositorio auditable mediante gestión de versiones, estados de configuración y trazabilidad.

## Cómo ejecutar (simulado)

No se requiere despliegue real. Este repositorio se utiliza para la práctica de Gestión de la Configuración del Software.

## Convenciones

- Commits: `chore`, `docs`, `feat` o `fix` + referencia `ISSUE-xx`.
- Versiones: SemVer (`vMAJOR.MINOR.PATCH`).
