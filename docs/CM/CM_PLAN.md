# Plan de Gestión de la Configuración

## Alcance

Este plan establece las convenciones básicas para identificar, versionar y controlar los elementos de configuración de la API de Inventario.

## Convenciones

- Versionado mediante SemVer.
- Cambios trazables mediante issues, commits y pull requests.
- Registro de estados en `CM_STATUS_REGISTER.md`.
- Liberaciones identificadas mediante tags y releases.
